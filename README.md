# Second-Brain

A personal "second brain" I built in Google's Gemini AI notebook: a growing, always-available memory for my thoughts, ideas and notes. I built it out of curiosity, not for profit, and it is a good example of how I like to work: try something new, see what happens, learn from it.

## Why I built it
I wanted to see how far an AI tool could go as a personal knowledge base. Ideas and thoughts get lost easily, and I was curious whether an AI could help me keep them organized and build a picture of how I think over time.

## How it works
1. **I feed it information myself.** Thoughts, ideas, notes and things I want to remember all go in manually. The system does not fetch information on its own.
2. **The AI builds a profile and archives everything.** It organizes what I give it, creates a profile from the material and stores it so I can come back to it later.
3. **Automations are handled by the AI tool itself.** I have not coded them myself. I configured what I wanted, and the tool takes care of the rest.

## What I learned
- Getting started takes very little: you do not need to write code to build something useful.
- The quality of the output depends directly on the quality of what you put in. Consistent, honest input makes a much better "memory".
- Building it made me curious about the next step: understanding how these tools work under the hood and eventually building parts of a system like this myself.
